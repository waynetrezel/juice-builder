# Ingredient model sources

Downloaded 2026-10-26 for the Juicebuilder visual concept. Blender imports use the included 2K glTF versions.

| Ingredient | Poly Haven asset | Author | License | Source |
|---|---|---|---|---|
| Lemon | `lemon` | Kuutti Siitonen | CC0 | https://polyhaven.com/a/lemon |
| Lime | `food_lime_01` | Oliver Harries | CC0 | https://polyhaven.com/a/food_lime_01 |
| Apple | `food_apple_01` | Oliver Harries | CC0 | https://polyhaven.com/a/food_apple_01 |
| Kiwi | `food_kiwi_01` | Oliver Harries | CC0 | https://polyhaven.com/a/food_kiwi_01 |
| Dandelion | `dandelion_01` | Rico Cilliers | CC0 | https://polyhaven.com/a/dandelion_01 |

Poly Haven states that its assets are CC0 and may be used for commercial work. Attribution is not required for the models; this manifest keeps provenance with the project. The animatic imports only the single dandelion specimen mesh; its render shows leaves and flower stems with no roots.

The aloe leaf at `../aloe/aloe-leaf-web.glb` was generated from the user's Hi3D workspace. The user confirmed it is okay to use for this project. The large original export is preserved separately in the same folder.

The okra pod and cross-sections are original Blender geometry with procedural materials, not a scanned asset. No suitable, clearly licensed photoreal okra source has been selected yet.
